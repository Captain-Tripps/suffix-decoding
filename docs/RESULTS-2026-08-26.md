## Read

- On **cold / single-shot** prompts, ngram-mod does nothing MTP was not already doing. Slightly slower within noise (same draft counts on easy/code/reason).
- On **warm repeat**, ngram-mod’s shared hash pool reuses the previous generation. Draft length jumps 102 → 131, accept 100 → 131, decode 43 → **62 t/s**. MTP-only does not get that lift.
- **hard_reason does not regress.** That was the kill-switch.

This is the SuffixDecoding paper’s shape on a toy agent loop, using llama.cpp ngram-mod (not a suffix tree yet). Justifies a custom SYCL build + suffix-tree port **for corpus / multi-request agent traces**, not for replacing production MTP on chat.

Do **not** promote `qwen3.8-27b-ngram` to preload until we see the same warm-repeat lift on real Agent Studio / tool-JSON traces and confirm cold-path noise stays small.
